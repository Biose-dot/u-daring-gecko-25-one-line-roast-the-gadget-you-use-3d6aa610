## The entry

`main.py` writes one roast to `/output/entry.txt`:

> My smartwatch buzzes to congratulate me for standing up, then nags
> me for sitting too long — the only coach that gaslights me hourly.

The roast is built for the judge brief: it names a gadget used every
day (the smartwatch), a concrete behaviour (congratulating a stand,
then nagging about sitting), and a fresh sting at the end — the
"coach" that gaslights its owner hourly.

## Running

```sh
python3 main.py   # writes the roast to /output/entry.txt
```
